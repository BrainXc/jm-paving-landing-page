# JM Paving & Sealcoating Landing Page

Responsive static landing page based on the supplied Canva design.

## Deploy

This is a static site. Deploy the repository directly to Vercel with no build command required.

## Included design

- Full-width hero banner
- Quote form
- Service cards
- About section with overlapping estimate callout
- Recent projects
- Client reviews
- Responsive mobile layout

The final visual assets from the design should be kept in `assets/` when syncing the complete local project.
